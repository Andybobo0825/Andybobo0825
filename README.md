## Featured Cloud Architecture & DevOps Projects

### [AWS Serverless Architecture — Magic Learning Platform](https://github.com/Andybobo0825/aws-serverless-architecture-pub)

**Focus:** Serverless architecture, identity and access control, content security, reliability, and cost governance

Terraform-managed learning platform built with Cognito RBAC, API Gateway, Lambda, DynamoDB PITR, private S3 origins, CloudFront, signed content access, CloudWatch, SNS, AWS Budgets, and infrastructure protection guardrails.

### [AWS CI/CD Pipeline on ECS Fargate](https://github.com/Andybobo0825/aws_pipeline_demo)

**Focus:** Container delivery automation, deployment traceability, and service health validation

End-to-end AWS delivery pipeline using CodePipeline, CodeBuild, ECR, ECS Fargate, ALB, CloudWatch, and Terraform. Container images are versioned for traceable deployments and validated through load balancer health checks.

### [AWS Incident Response and Observability Lab](https://github.com/Andybobo0825/aws-incident-response-observability-lab)

**Focus:** Monitoring, alerting, fault injection, incident investigation, and recovery validation

Observability and incident-response environment using CloudWatch dashboards, metrics, logs, alarms, SNS notifications, ECS Auto Scaling, controlled failure scenarios, operational runbooks, recovery verification, and RCA documentation.
